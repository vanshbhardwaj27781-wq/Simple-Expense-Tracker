# Simple Expense Tracker

## 📌 Project Overview
This project is a **Simple Expense Tracker** created as part of the **Veda Technology Data Analytics Track**. The purpose of this project is to track daily expenses, categorize spending, and analyze monthly expenses using Microsoft Excel.

## 🎯 Objective
- Track daily expenses
- Categorize expenses properly
- Calculate monthly expenses
- Compare category-wise spending
- Understand spending patterns through charts

## 🛠️ Tools Used
- Microsoft Excel
- Excel Formulas
- SUMIFS
- Data Validation
- Excel Tables
- Charts

## 📊 Dataset
The tracker contains:
- Date
- Description
- Category
- Payment Method
- Amount
- Month

Categories include **Food, Transport, Housing, Bills, Entertainment, Health, Shopping, and Education**.

## 📈 Key Features
- Daily expense tracking
- Category dropdowns
- Payment method dropdowns
- Automatic expense totals
- Monthly summary
- Category-wise analysis
- Expense distribution chart
- Monthly expense chart

Through this project, I practiced Excel data organization, categorization, formulas, data validation, summarization, and basic data visualization.
